# Code of Conduct

We value the participation of every member of the community and we are dedicated to providing a welcoming and supportive environment for all. 

With this Code of Conduct, we hope to make clear what is expected when you contribute to this project. By contributing to this project, you accept to abide by the following:

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- When submitting a pull request
  - Be patient, your pull request might not be accepted directly
  - Be open to feedback
- When reviewing a pull request
  - Be constructive; focus on the code, not the coder
  - Provide specific, actionable feedback
  - Handle disagreements constructively; consider asking a third developer for their perspective
